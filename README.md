# WeatherCast 73.76

Генератор аудиопрогноза погоды для радиоэфира.
Радиостанция «Радио 7» — Ростов-на-Дону, частота 73.76 МГц. Автор: AVAIM0013.

Текущая версия и статус — в файле [`VERSION`](VERSION).
История изменений — в [`CHANGELOG.md`](CHANGELOG.md).

## Что это

Программа автоматически получает прогноз погоды (Open-Meteo), формирует
текст для эфира, синтезирует голос и накладывает его на музыкальный фон,
сохраняя готовый файл `ПОГОДА.wav`. Рассчитана на регулярный выход в эфир
без участия человека.

## Что умеет

- Полный конвейер: данные → текст → голос → микс с фоном → `ПОГОДА.wav`.
- Три синтезатора с автоперебором: Edge TTS (Microsoft) → gTTS (Google) →
  Piper (офлайн).
- Интерфейс PySide6/Qt: кнопка запуска с индикатором и журналом, выбор места
  сохранения, порядок и включение синтезаторов, выбор голоса, расписание
  (несколько времён, ежедневный повтор).
- Портативная сборка под Windows 10 (onedir, PyInstaller): где запустил —
  там и работает, перенос — копированием папки.
- Автосборка и автотест одной командой.

## Запуск

- GUI (Linux): `python3 weather_gui.py`
- CLI (Linux): `python3 weather.py`
- Windows (ВМ): `D:\WeatherCast 73.76\WeatherCast-73.76.exe` —
  запускать через `ЗАПУСК_ПРОГРАММЫ.bat` (см. [`docs/RULES.md`](docs/RULES.md)).

## Сборка

```bash
bash "Разработка/Скрипты сборки/wtts-build.sh" cycle
```

При сборке рядом с готовой программой обновляется `ВЕРСИЯ.txt`
(дата, версия, статус, автор, контрольная сумма исходника).
