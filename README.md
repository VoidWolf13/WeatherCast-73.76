# WeatherCast 73.76

Генератор аудиопрогноза погоды для радиоэфира.
Радиостанция «Радио 7» — Ростов-на-Дону, частота 73.76 МГц. Автор: AVAIM0013.

Текущая версия и статус — в файле [`VERSION`](VERSION).
История изменений — в [`CHANGELOG.md`](CHANGELOG.md).

## Скачать

Готовая сборка под Windows 10 x64 — в разделе
[**Releases**](https://github.com/VoidWolf13/WeatherCast-73.76/releases/latest):

- **`WeatherCast-73.76-0.23.1-win64.zip`** (~373 МБ) — распаковать целиком
  и запустить `WeatherCast-73.76.exe`.

## Что это

Программа автоматически получает прогноз погоды (Open-Meteo), формирует
текст для эфира, синтезирует голос и накладывает его на музыкальный фон,
сохраняя готовый файл `ПОГОДА.wav`. Рассчитана на регулярный выход в эфир
без участия человека.

## Что умеет

- Полный конвейер: данные → текст → голос → микс с фоном → `ПОГОДА.wav`.
- Три синтезатора с автоперебором: Edge TTS (Microsoft) → gTTS (Google) →
  Piper (офлайн).
- Интерфейс PySide6/Qt в духе дашборда: три KPI-карточки (последний выпуск
  с длительностью голоса, следующий слот, активные синтезаторы); главное
  действие с индикатором, расписание, порядок и голоса синтезаторов,
  путь сохранения, прослушивание результата, сворачиваемый журнал.
- Портативная сборка под Windows 10 (onedir, PyInstaller): где запустил —
  там и работает, перенос — копированием папки.
- Автосборка и автотест одной командой.
- Выпуск по расписанию двумя независимыми способами: таймером в окне и
  планировщиком Windows (`ПОГОДА_ПО_РАСПИСАНИЮ.bat 09:00` → тот же exe с
  `--run --slot`). Обе стороны пишут исход в общий `runstate.json`, поэтому
  запуск из планировщика виден в окне, а один слот не срабатывает дважды.

## Запуск

**Windows — конечному пользователю:** распаковать архив из раздела
[Releases](https://github.com/VoidWolf13/WeatherCast-73.76/releases/latest)
целиком и запустить `WeatherCast-73.76.exe`. Никаких батников не нужно.

- GUI (Linux): `python3 weather_gui.py`
- CLI (Linux): `python3 weather.py`
- Windows (ВМ, разработка): `D:\WeatherCast 73.76\WeatherCast-73.76.exe` —
  через `ЗАПУСК_ПРОГРАММЫ.bat` (обход virtiofs, [`docs/RULES.md`](docs/RULES.md) п. 7).
- Windows, выпуск по расписанию (ВМ): `ПОГОДА_ПО_РАСПИСАНИЮ.bat 09:00` —
  exe в консольном режиме (`--run --slot`); регистрация в планировщике —
  [`docs/RULES.md`](docs/RULES.md), п. 8.

## Сборка

```bash
bash "Разработка/Скрипты сборки/wtts-build.sh" cycle
```

Два файла версии — не дубликат, у них разные роли:

| Файл | Где лежит | Кто пишет | Зачем |
|---|---|---|---|
| `VERSION` | корень проекта, в git | правит человек | **единственный источник** версии и статуса (см. [`docs/RULES.md`](docs/RULES.md) п. 9); его читает код |
| `ВЕРСИЯ.txt` | папка готовой сборки | генерирует `wtts-build.sh` при каждой сборке | **штамп сборки**: дата и время, версия, статус, автор, станция, md5 исходника — по нему видно, из какого кода собран лежащий exe. В git не хранится |
