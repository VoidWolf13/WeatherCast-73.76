# Устройство программы

## Компоненты

| Модуль | Роль |
|---|---|
| `weather.py` | ядро: запрос Open-Meteo → текст прогноза → синтез речи → микс с фоном |
| `weather_gui.py` | интерфейс PySide6/Qt: запуск, настройки, расписание, журнал |
| `assets/` | музыкальный фон `WEATHER_2023_IIII.wav` |
| `voices/` | модели голосов Piper (`.onnx`) |
| `Разработка/Скрипты сборки/` | `wtts-build.sh` — сборка + выкладка + автотест |

## Конвейер

```
Open-Meteo → build_text() → синтез (Edge TTS → gTTS → Piper)
          → подгонка длительности → микс с фоном → ПОГОДА.wav
```

1. **Данные.** Open-Meteo, хосты перебираются по порядку
   (historical-forecast-api → api.open-meteo → ensemble-api). Ветер в м/с,
   часовой пояс Europe/Moscow, глубина 2 суток.
2. **Текст.** `build_text()` собирает блоки «сейчас / день / ночь / завтра»,
   числа переводятся в слова, детали режутся по приоритету при нехватке
   времени. Правила — [`TEXT-RULES.md`](TEXT-RULES.md).
3. **Синтез.** Три движка с автоперебором; сбой одного не валит эфир.
4. **Микс.** Голос накладывается на фон с задержкой 4 с, голос чуть громче
   фона; длинные паузы подрезаются.
5. **Вывод.** Файл `ПОГОДА.wav` рядом с программой (путь задаётся в UI).

## Сборка

PyInstaller (onedir) под Wine + Windows-Python; в сборку включаются ffmpeg/
ffprobe, piper с DLL, espeak-ng-data, onnxruntime, модели голосов и фон.
Готовая папка выкладывается в LinWinData (в ВМ Win10 видна как диск D:).
Версия и статус берутся из файла [`../VERSION`](../VERSION).
