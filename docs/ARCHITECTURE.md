# Устройство программы

## Компоненты

| Модуль | Роль |
|---|---|
| `weather.py` | ядро: запрос Open-Meteo → текст прогноза → синтез речи → микс с фоном |
| `weather_gui.py` | интерфейс PySide6/Qt: KPI-карточки состояния, главное действие,
  расписание, синтезаторы, журнал |
| `assets/` | музыкальный фон `WEATHER_2023_IIII.wav` |
| `voices/` | модели голосов Piper (`.onnx`) |
| `Разработка/Скрипты сборки/` | `wtts-build.sh` — сборка + выкладка + автотест |

## Файлы состояния (рядом с программой)

| Файл | Кто пишет | Что внутри |
|---|---|---|
| `config.json` | только GUI | пользовательские настройки: путь, синтезаторы, расписание |
| `runstate.json` | GUI **и** CLI | служебный журнал: `last_run`, `slot_results`, `fired` |
| `weather.log` | оба | текст текущего прогона |

Разделение намеренное. Раньше исход прогона лежал в `config.json`, поэтому
запуск из планировщика по CLI не был виден в интерфейсе, а слот мог сработать
дважды (GUI и планировщик не знали друг о друге). Теперь обе стороны пишут
в `runstate.json` через `weather.record_run()`:

- `last_run` — исход последнего прогона (успех/ошибка, движок, что пропущено);
  статус-строка GUI читает его оттуда, а не из своих настроек;
- `slot_results` — исход по каждому времени расписания для отметок в строках;
- `fired` — отметка «слот `YYYY-MM-DD HH:MM` уже сработал»: `mark_slot()`
  ставится до старта, поэтому ни второй запуск, ни ручной пуск в ту же минуту
  не дадут дубль в эфире.

`weather.py --run --slot HH:MM` — запуск по расписанию из CLI (планировщик
Windows): проверяет `fired`, пишет исход в `runstate.json` и возвращает
`{"ok": false, "skipped_slot": "HH:MM"}`, если слот уже отработал.

## Конвейер

```
Open-Meteo → build_text() → синтез (Edge TTS → gTTS → Piper)
          → подгонка длительности → микс с фоном → ПОГОДА.wav
```

1. **Данные.** Open-Meteo, хосты перебираются по порядку
   (historical-forecast-api → api.open-meteo → ensemble-api). Ветер в м/с,
   часовой пояс Europe/Moscow, глубина 2 суток.
2. **Текст.** `build_text()` собирает блоки «сейчас / день / ночь / завтра»,
   числа переводятся в слова, детали режутся по приоритету при нехватке
   времени. Правила — [`TEXT-RULES.md`](TEXT-RULES.md).
3. **Синтез.** Три движка с автоперебором; сбой одного не валит эфир.
4. **Микс.** Голос накладывается на фон с задержкой 4 с, голос чуть громче
   фона; длинные паузы подрезаются.
5. **Вывод.** Файл `ПОГОДА.wav` рядом с программой (путь задаётся в UI).

## Сборка

PyInstaller (onedir) под Wine + Windows-Python; в сборку включаются ffmpeg/
ffprobe, piper с DLL, espeak-ng-data, onnxruntime, модели голосов и фон.
Готовая папка выкладывается в LinWinData (в ВМ Win10 видна как диск D:).
Версия и статус берутся из файла [`../VERSION`](../VERSION).
